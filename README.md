## 🧺 About the Project

**Laundry Express** is a fast, reliable, and user-friendly web application that ensures laundry pickup and delivery service within **90 minutes**.

It was designed to simplify your laundry experience with a digital-first approach using modern technologies and a focus on speed and customer satisfaction.

---

## 🔥 Key Features

- ⏱️ **Fast 90-Minute Delivery Promise**
- 🧼 **Support for All Laundry Types** (clothes, curtains, bedding, etc.)
- 📍 **Location-based Service Detection**
- 📅 **Real-Time Booking and Scheduling**
- 🧾 **Order Tracking with Status Updates**
- 💳 **Payment Integration (UI only)**
- 🤖 **AI Chat Support**
- 🧠 **Smart Laundry Recommendations (AI-based)**

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/OneTeraByte7/Laundry-Express.git
   cd Laundry-Express
    ```
2. Install dependencies:
   ```bash
   npm install
   cd client
   npm install
    ```
3. Run Server:
   ```bash
   # Backend
    npm start

    # Frontend
    cd client
    npm start
   ```
